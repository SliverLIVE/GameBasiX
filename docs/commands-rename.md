# Command rename in 1.2

GameBasiX 1.2 renames its built-in library so the names follow one scheme.
The language core (`IF`, `FOR`, `TYPE`, `PRINT`, `INKEY$`, the `$`/`%`
suffixes) is untouched, and nothing else about the commands changed – only
their spellings.

## The scheme

* A resource comes first, the action follows: `SPRITE_DRAW`, `FILE_SIZE`,
  `NET_CONNECT`, `STEAM_P2P_SEND`.
* Without a resource the action comes first: `DRAW_LINE`, `SET_VIEWPORT`,
  `WAIT_INPUT`, `LIMIT_FPS`.
* Reading a value needs no `GET`: `SCREEN_WIDTH`, `MOUSE_COUNT`.
* States read as properties: `FILE_EXISTS`, `SOUND_PLAYING`, `NET_CONNECTED`,
  `STEAM_READY`.
* No abbreviations: `SHL`/`SHR` instead of `ASL`/`ASR`, `FILE_READ_DOUBLE`
  instead of `READIEEE`, `SOURCE_FILE$` instead of `CODEFILE$`.
* `GETTIMER`/`GETTIMERALL` became `DELTA_TIME`/`ELAPSED_TIME`, because "timer"
  did not say that one of them resets.

`VIEWPORT` (which set the region) is now `SET_VIEWPORT`, and `GETVIEWPORT`
took the name `VIEWPORT`.
