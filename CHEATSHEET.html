Clears the screen in the given colour and remembers it for the following frames.

Returns 1 while the window runs fullscreen, otherwise 0.

Returns the height of the drawing area in pixels.

Draws internally at a fixed resolution and stretches the result to the window.

Opens the game window with a width and height in pixels.

SCREEN_SHOWcommand

Shows the finished frame and starts the next one. Usually the last statement of the main loop.

SCREEN_SIZE w,hcommand

Writes the width and height of the current window into the two variables.

SCREEN_WIDTH()function

Returns the width of the drawing area in pixels.

SET_ALPHA_MODE acommand

Decides how transparency is blended while drawing: 0 normal, positive values additive, negative values as alpha with 1+value.

SET_ALPHA_TEST valuecommand

Sets the threshold below which pixels become fully transparent when images are loaded.

SET_COLOR_KEY colorcommand

Remembers a colour that becomes transparent the next time images are loaded. Sprites already loaded stay as they are.

SET_SMOOTHING oncommand

Turns smooth shading on or off: with 1, polygons and scaled sprites are filtered instead of sampled sharply.

SET_VIEWPORT x,y,w,hcommand

Sets the region that is drawn into. Everything outside it is clipped.

VIEWPORT x,y,w,hcommand

Reads the current viewport into the four variables.

WINDOW_TITLE "text"command

Changes the window title while the program is running.

Holds the program until a key is pressed or released. It returns no value.

MOUSE_MOVE x,ycommand

Moves the mouse pointer to the given position inside the window.

MOUSE_PRESSED(button)function

Returns 1 only in the frame the button was pressed: 0 left, 1 right, 2 middle.

MOUSE_STATE mx,my,left,rightcommand

Writes the mouse position and button state into four variables: x, y, left button, right button.

MOUSE_WAITcommand

Holds the program until a mouse button is pressed. It returns no value.

SET_SYSTEM_POINTER oncommand

A loop that runs at least once and is tested at the end with UNTIL.

RETURNkeyword

Leaves a FUNCTION and returns the value behind it; inside a SUB it ends the call without a value.

Multiple choice: checks the CASE blocks in turn, DEFAULT catches the rest.

The object itself inside a METHOD. self.x reads or writes a field, self.method() calls one of its own methods.

Step size of a FOR loop; negative values count downwards.

THROWkeyword

Raises an error with the given message that TRY/CATCH can catch.

TOkeyword

Separates the start and the end of a FOR loop.

TRYkeyword

Starts a block whose runtime errors can be caught by CATCH.

Condition behind a CATCH: the block only runs when it is true; the message is in the error variable.

WHILEkeyword

Loop that checks its condition before each pass and runs until WEND.
