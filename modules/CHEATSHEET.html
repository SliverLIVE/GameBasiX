GameBasiX · central modules

Modules cheat sheet

Seven drop-in modules for UI, game math, JSON, 2D physics, 3D rendering, animation curves and Steamworks. Add one through the Modules dock or copy its single INCLUDE line. Every command below is documented in full in the module's HELP.md.

7 modules 1 INCLUDE each pure GBX where possible full API in HELP.md
Which module? UI Math JSON Box2D OpenGL 3D Easing Steam

Which module, when?

ModuleReach for it when you need…Runtime
UI Windows, labels, buttons, toggles, sliders, text fields, dropdowns, listboxes, keyboard focus and light/dark themes. Pure GBX · interpreter, EXE, HTML5
MATH Clamp/lerp/remap, angles, VEC2, RECT2, collision tests, random ranges, noise and curves. Pure GBX · interpreter, EXE, HTML5
JSON Config files, savegames, level data: parse, read by path, edit, write back. Pure GBX · interpreter, EXE, HTML5
BOX2D 2D rigid bodies: stacked boxes, joints, contacts, forces, point/ray queries. INLINE C++ · compiler on first run; HTML5 included
OPENGL3D 3D scenes, meshes and textures rendered into the normal GBX screen. INLINE C++ · OpenGL 1.1 on Windows, software in HTML5
EASING One-line animation curves between two values. Native archive; IDE copies it · HTML5 fallback
STEAM Friends, P2P packets, achievements, stats, leaderboards, cloud files, lobbies, rich presence, overlay, auth tickets and DLC. INLINE C++ · Steamworks flat API loaded at runtime; HTML5 stays neutral

Adding a module: open the Modules dock and press Add. The IDE writes the INCLUDE line, and for native modules copies the archive and registers it under [native] libs. Removing the module reverses that.

Pure GBX · all targets

UI

INCLUDE "modules/ui/UI.gbx"

A flat widget toolkit that draws itself with normal GBX commands. One widget store per program; widgets belong to the window that was opened last.

Set up

GLOBAL app AS UI
app.init()

GLOBAL win = app.window("Settings", 40, 40, 420, 360)
GLOBAL nameF = app.field("Player", 20, 56, 260, "Player one")
GLOBAL vol = app.slider("Volume", 20, 116, 260, 0, 100, 1, 70)
GLOBAL start = app.button("Start", 20, 300, 120, 36, 1)
app.endWindow()

WHILE TRUE
  SCREEN_CLEAR app.bg
  app.run()
  IF app.clicked(start) THEN ' …
  SCREEN_SHOW
WEND

Widgets

window(title$, x, y, w, h)Draggable window with close button; starts the client area
panel(title$, x, y, w, h)Flat group box
label(text$, x, y, w = 0)Single line label; w = 0 fits the text
heading(text$, x, y, w = 0)Accent heading with underline
separator(x, y, w)One pixel divider
button(text$, x, y, w, h, primary = 0)Flat button; primary uses the accent
toggle(text$, x, y, checked = 0)Checkbox-style toggle
slider(title$, x, y, w, lo, hi, step, value)Numeric slider with value label
progress(title$, x, y, w, value)0…1 progress bar
field(title$, x, y, w, text$ = "")Editable single-line text field
dropdown(title$, x, y, w, options$, index = 0)Popup selection; options are a|b|c
listbox(title$, x, y, w, h, options$, index = 0)Scrollable list
endWindow()Close the client area; later widgets go to the next window

Read and change state

app.value(id)Number of a slider/progress
app.text$(id)Text of a field/label or selected option
app.clicked(id)1 on the frame a button/toggle was activated
app.changed(id)1 when a field/dropdown/list changed
app.setValue(id, v)Set a slider/progress value
app.setText(id, s$)Set a label/field text
app.setOptions(id, s$)Replace dropdown/list options
app.enable(id, flag)Enable or grey out a widget
app.openWin(id) / closeWin(id)Show or hide a window
app.focusOn(id)Move keyboard focus
app.clear()Remove every widget and start a new screen

Input, theme and rules

app.vmouse(x, y, down)Feed virtual mouse input (demos, headless tests)
app.vkey(code) / app.vtext(s$)Feed a key or typed text
app.vm% = 0Back to real input
app.theme("dark"|"light")Switch the built-in palette
app.bg, app.surface, app.accent, app.accentInkCustom palette fields; also surface2, titleBar, line, ink, inkDim, danger, field
app.titleH, app.pad, app.rowHGeometry metrics

Remember: create widgets once, before the frame loop. Call app.run() once per frame after drawing your background. Coordinates are relative to the window's client area; ESC is deliberately left to the game.

Math

INCLUDE "modules/math/MATH.gbx"

Everyday gameplay math without a C++ block. Angles are degrees, like SIN/COS/ATAN; positive turns clockwise on screen.

MATH_INV_LERP(a, b, v)Where v lies between a and b
MATH_REMAP(v, inLo, inHi, outLo, outHi)Move a value between ranges
MATH_REMAP_CLAMPED(…)Same, clamped to the output range
MATH_SMOOTHSTEP(e0, e1, v)Hermite 0…1 with soft ends
MATH_MOVE_TOWARD(cur, target, step)Step at most step towards target
MATH_WRAP(v, lo, hi)Wrap into [lo, hi)
MATH_PINGPONG(v, len)Bounce between 0 and len
MATH_SNAP(v, step)Round to a multiple of step
MATH_DEADZONE(v, dead)Rescale a -1…1 stick around a centre dead zone
MATH_DAMP(cur, target, lambda, dt)Frame-rate independent smoothing
MATH_DAMP_ANGLE(…)Same for an angle, the short way round
MATH_NEAR(a, b[, eps])1 when close; default epsilon MATH_EPS
MATH_SAFE_DIV(a, b[, fallback])a/b, or fallback when b is near zero

Angles

MATH_ANGLE_WRAP(deg)Normalize to -180…180
MATH_ANGLE_DIFF(from, to)Shortest signed turn
MATH_ANGLE_LERP(from, to, t)Interpolate the short way round
MATH_ANGLE_LERP_CLAMPED(…)Same, with t clamped
MATH_ANGLE_APPROACH(cur, target, step)Turn at most step degrees
MATH_ANGLE_BETWEEN(x1, y1, x2, y2)Direction from the first point to the second
MATH_DIR_X(deg) / MATH_DIR_Y(deg)Unit direction as COS/SIN

VEC2

r.centerX() / r.centerY()Centre point

MATH_RECT_OVERLAP_X / _YPenetration along one axis; 0 if apart

Random & noise

MATH_RAND() / MATH_RAND_RANGE(lo, hi)Decimal 0…1, or inside a range
MATH_RAND_INT(lo, hi)Whole number, both limits included
MATH_RAND_CHANCE(p) / MATH_RAND_SIGN()1 with probability p; -1 or 1
MATH_RAND_INDEX(n)0…n-1, or -1 for an empty array

MATH_HASH1(ix[, seed]) / HASH2(ix, iy[, seed])Hash of a lattice coordinate
MATH_NOISE(x[, seed]) / NOISE2(x, y[, seed])Smooth value noise, 0…1
MATH_FBM(x[, oct[, seed]])Layered 1D noise, 4 octaves by default
MATH_FBM2(x, y[, oct[, lac[, gain[, seed]]]])Layered 2D noise

Curves & springs

MATH_BEZIER2(a, b, c, t)Quadratic Bezier between numbers
MATH_BEZIER3(a, b, c, d, t)Cubic Bezier between numbers
MATH_CATMULL_ROM(a, b, c, d, t)Smooth spline through b and c

Constants: MATH_PI, MATH_TAU, MATH_E, MATH_DEG2RAD, MATH_RAD2DEG, MATH_EPS. References: VEC2 and RECT2 are reference values - b = a aliases the same object. Use b.copyFrom(a.x, a.y) or a fresh LOCAL b AS VEC2 for a copy. Springs: pass DELTA_TIME() / 1000.0 as dt.

Pure GBX · all targets

JSON

INCLUDE "modules/json/JSON.gbx"

Parse, read, edit and write JSON without a C++ block. Objects become DICTs, arrays become index-keyed DICTs, so a document can also be walked with the normal dictionary commands.

Parse, read and write

JSON_PARSE(text$)Parse a value; null on error
JSON_VALID(text$)1 when the text is valid JSON
JSON_ERROR$() / JSON_ERROR_POS()Last parse error and position
JSON_READ(path$) / JSON_SAVE(v, path$)Read a UTF-8 file, or write pretty JSON
JSON_WRITE$(v)Compact one-line JSON
JSON_WRITE_PRETTY$(v)Indented with two spaces
JSON_WRITE_INDENTED$(v, n)Indented with n spaces
JSON_ESCAPE$(text$)Escape a string without the quotes

Read by path

JSON_GET(doc, path$)Raw value, 0 when missing
JSON_HAS(doc, path$)1 when the path exists, also for null
JSON_GET_TYPE(doc, path$)JSON_TYPE_*, -1 when missing
JSON_GET_NUM(doc, path$, fallback)Number; booleans become 0/1
JSON_GET_TEXT$(doc, path$, fallback$)Text or fallback
JSON_GET_BOOL(doc, path$, fallback)Boolean; numbers become 1/0
JSON_COUNT(doc, path$)Array length, object keys or text length
JSON_KEY$(doc, path$, i) / JSON_AT(doc, path$, i)Key or value by position

Build and edit

JSON_OBJECT() / JSON_ARRAY()New empty containers
JSON_SET(doc, path$, v)Store, creating missing containers
JSON_SET_NULL / BOOL / NUM / TEXTTyped variants
JSON_APPEND(doc, path$, v)Append to an array; returns the index or -1
JSON_APPEND_NULL / BOOL / NUM / TEXTTyped variants
JSON_REMOVE(doc, path$)Remove a key/element; arrays close the gap
JSON_CLEAR(doc, path$) / JSON_CLONE(v)Empty a container; deep copy a value
JSON_MAKE_NULL / TRUE / FALSE / BOOL(f)Marked scalar values

Inspect a value

JSON_KIND(v) / JSON_TYPE_NAME$(v)Type number or name
JSON_IS_NULL / BOOL / NUMBER / STRING / OBJECT / ARRAYType tests
JSON_BOOL(v) / JSON_NUM(v) / JSON_TEXT$(v)Coerce to a scalar
JSON_TYPE_NULL … ARRAYConstants 0…5
 
doc = JSON_PARSE("{""player"":{""hp"":100}}")
PRINT JSON_GET_NUM(doc, "player.hp", 0)
JSON_SET_NUM doc, "player.hp", 90
PRINT JSON_WRITE$(doc)

Paths: player.name, inventory[2].count, [0].id; ' is the document itself. Arrays: parsed documents use a DICT with the marker key "$"; skip it when walking with DICT_KEY$. Parse errors never stop the program - test JSON_VALID or read JSON_ERROR$().

INLINE C++ · Box2D-Lite

Box2D

INCLUDE "modules/box2d/BOX2D.gbx"

Boxes with gravity, friction, stacking, point-to-point joints, contacts and ray queries. All physics runs in C++; BASIC creates bodies and reads their state. Units are free - the examples use pixels.

Set up

BOX2D_WORLD 0, 900, 12       ' gravity x/y, iterations
floor = BOX2D_BOX(480, 660, 960, 60, 0, 1)
crate = BOX2D_BOX(480, 80, 60, 60, 0, 0)

WHILE TRUE
  BOX2D_STEP 1.0 / 60.0
  ' draw with BOX2D_CORNER_X/Y or BOX2D_DEBUG_DRAW()
  SCREEN_SHOW
WEND

World

BOX2D_WORLD [gx, gy[, iter]]New world, defaults 0, 900, 12
BOX2D_CLEARRemove all bodies and joints, keep gravity
BOX2D_GRAVITY gx[, gy]Change gravity
BOX2D_ITERATIONS nSolver iterations per step
BOX2D_SOLVER [warm, posCorr, accum]Solver switches, all on by default
BOX2D_STEP [dt]Advance; dt clamped to 1/240…1/30
BOX2D_COUNT()Live bodies

Bodies

BOX2D_BOX x, y, w, h, angle, isStatic[, friction[, mass]]Create a box; returns its ID
BOX2D_REMOVE id / BOX2D_ALIVE(id)Remove a body and its joints; test an ID
BOX2D_X(id) / BOX2D_Y(id) / BOX2D_ANGLE(id)Centre and rotation (radians)
BOX2D_DEGREES(id)Rotation in degrees
BOX2D_VX / VY / SPEED / SPINVelocity and angular velocity
BOX2D_WIDTH / HEIGHT / HALF_WIDTH / HALF_HEIGHTSize
BOX2D_MASS / FRICTION / IS_STATICMass (0 static), friction, static flag
BOX2D_CORNER_X(id, i) / CORNER_Y(id, i)Rotated corner: 0 TL, 1 TR, 2 BR, 3 BL

Change a body

BOX2D_PLACE id, x, y[, angle]Move and optionally turn at once
BOX2D_TURN id, rad / SET_SPIN id, radSet rotation or angular velocity
BOX2D_SET_VELOCITY id, vx[, vy]Set velocity
BOX2D_SET_MASS id, m / SET_FRICTION id, fChange mass/inertia or friction; mass 0 = static
BOX2D_FORCE id, fx[, fy] / TORQUE id, tForce/torque for the next step

Joints

BOX2D_JOINT_COUNT() / JOINT_REMOVE idCount or remove joints
BOX2D_JOINT_AX / AY / BX / BYWorld anchors on both bodies
BOX2D_JOINT_SOFTNESS id, v / BIAS id, vConstraint softness and position correction

Contacts, queries, debug

BOX2D_CONTACT_COUNT()Contact points from the last step
BOX2D_CONTACT_BODY(i, which)Body ID; which 0 or 1
BOX2D_CONTACT_VALUE(i, what)0/1 position, 2/3 normal, 4 depth, 5 impulse
BOX2D_TOUCHING(a, b)Contact points between two bodies
BOX2D_AT x, y[, static]Body under a point, 0 = none
BOX2D_RAY x, y, dx, dy[, maxT]Ray query; returns the body
BOX2D_HIT(what)0/1 point, 2 t, 3/4 normal of the last ray
BOX2D_DEBUG_DRAW()Draw the physics state with normal GBX commands
BOX2D_DEBUG_FLAGS flags / DEBUG_COLORSChoose layers and colours

Remember: boxes only; one point-to-point joint type; no continuous collision detection, so very fast bodies can tunnel. Body IDs stay valid after removals. x/y is the centre, angle is in radians. First run compiles the INLINE block, so a C++ compiler must be configured in GBX Studio.

OpenGL 3D

Native archive · HTML5 fallback

Easing

INCLUDE "modules/easing/EASING.gbx"

The smallest animation tool: interpolate two numbers with one of four curves. The IDE copies libeasing.a into the project and registers it; the HTML5 player compiles the same curves directly.

One command

EASE_VALUE start, end, tLinear interpolation at t, clamped 0…1
EASE_VALUE start, end, t, modeSame with a curve

Modes: 0 linear · 1 smoothstep · 2 cubic in/out · 3 back out.

x = EASE_VALUE(0, 320, t, 1)   ' smoothstep
y = EASE_VALUE(80, 400, t, 3)  ' back out

When to use Math instead

For gameplay math (vectors, collision, springs, noise) use the MATH module. For full animation curves with custom control points use MATH_BEZIER2/3 or MATH_CATMULL_ROM. EASING is the one-call option for menus, camera slides and UI pops.

Removing the module deletes the copied archive and its [native] entry again. The archive in modules/easing/lib is never touched.

INLINE C++ · Steamworks

Steam

INCLUDE "modules/steam/STEAM.gbx"

The complete STEAM_* set: friends, P2P packets, achievements, statistics, leaderboards, cloud files, lobbies, rich presence, overlay, auth tickets and DLC. The wrapper loads the Steamworks flat API at runtime, so the project builds without the SDK; without the library every command returns a neutral value and STEAM_ERROR$() says why.

Set up

INCLUDE "modules/steam/STEAM.gbx"

IF STEAM_INIT() = 1 THEN
  WHILE TRUE
    STEAM_RUN              ' pump callbacks every frame
    ' ...
  WEND
ENDIF

Put steam_api64.dll (or the platform library) next to the program and a steam_appid.txt or app id beside it. GBX_STEAM_LIB points at a library elsewhere. The HTML5 player has no Steam and stays neutral.

Identity & friends

STEAM_RUN / STEAM_READY()Pump callbacks; 1 while ready
STEAM_NAME$() / STEAM_ID$() / STEAM_APP_ID()Own persona, SteamID as text, app id
STEAM_FRIENDS() / STEAM_FRIEND_NAME$(i) / STEAM_FRIEND_ID$(i) / STEAM_FRIEND_STATE(i)Friend list
STEAM_ERROR$()Last error text

Peer-to-peer

STEAM_P2P_SEND id$, text$[, channel[, reliable]]Send a packet; returns bytes sent
STEAM_P2P_AVAILABLE([channel]) / STEAM_P2P_RECV$([channel])Pending bytes; read one packet
STEAM_P2P_FROM$()Sender of the last packet
STEAM_P2P_ACCEPT id$ / STEAM_P2P_CLOSE id$Accept or close a session
STEAM_P2P_STATE(id$)0 none, 1 connecting, 2 connected, 3 relayed

Progress & platform

STEAM_STAT(name$) / STEAM_STAT_F(name$)Integer or float statistic
STEAM_STAT_SET name$, value / STEAM_STAT_SETF name$, value / STEAM_STORESet and store stats
STEAM_BOARD name$[, ascending] / STEAM_BOARD_SCORE points[, keepbest]Open a board; upload a score

STEAM_CLOUD_WRITE file$, text$ / STEAM_CLOUD_READ$(file$) / STEAM_CLOUD_EXISTS(file$) / STEAM_CLOUD_DELETE file$Steam Cloud files
STEAM_LOBBY_CREATE [slots[, kind]] / STEAM_LOBBY_JOIN id$ / STEAM_LOBBY_LEAVELobby lifecycle
STEAM_LOBBY_SET key$, value$ / STEAM_LOBBY_GET$(key$)Lobby data

Keep STEAM_RUN in the main loop - achievements, lobbies and asynchronous results only arrive through its callbacks. SteamIDs are text in BASIC and numbers internally; invalid ids set STEAM_ERROR$(). The module compiles into the program and needs only the runtime library beside it.
